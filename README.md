# Работа №2 — задание №1

Интерпретатор операций над целочисленными массивами на C++14.

Если нужно подготовиться к объяснению, сначала прочитайте `EXPLANATIONS.md`.
Там программа разобрана простыми словами без предположения, что читатель хорошо знает C++.

## Что реализовано

- все команды из задания: `Load`, `Save`, `Rand`, `Concat`, `Free`, `Remove`, `Copy`, `Sort`, `Shuffle`, `Stats`, `Print`;
- хранение массивов по именам в префиксном дереве;
- собственная пирамидальная сортировка на основе косой кучи;
- проверка имён, чисел, индексов, диапазонов и файлов;
- пропуск невалидных чисел при `Load`;
- обработка каждой ошибочной команды без аварийного завершения;
- динамические массивы без STL-контейнеров;
- конструктор копирования, оператор присваивания и деструктор у владеющих памятью классов.

## Сборка и запуск

Из корня репозитория:

```bash
cmake -S . -B build
cmake --build build
./build/task_01 task_01/commands.txt
```

Если путь к файлу команд не передан, программа пытается открыть `task_01/commands.txt`.

## Как объяснить решение

### Префиксное дерево

Каждая вершина соответствует одному символу имени. Путь от корня до конечной вершины образует имя массива. В конечной вершине хранится указатель на сам массив. Поиск зависит от длины имени, а она ограничена 16 символами: `O(L)`.

### Косая куча и сортировка

Косая куча — бинарное дерево, в корне которого находится минимальный или максимальный элемент. Главная операция `meld` сливает две кучи и после каждого шага меняет детей местами. Для сортировки все числа добавляются в кучу, а затем по одному извлекаются из корня.

- добавление и удаление: амортизированно `O(log n)`;
- сортировка: `O(n log n)`;
- дополнительная память сортировки: `O(n)`.

### Остальные сложности

- `Load`, `Save`, `Concat`, `Copy`, `Remove`, `Shuffle`, `Print`: `O(n)`;
- `Stats`: `O(n^2)`, потому что частота каждого значения считается простым двойным циклом;
- `Free`: `O(1)` для массива, память освобождается оператором `delete[]`.
