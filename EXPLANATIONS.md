# Как очень просто объяснить вторую лабораторную

В репозитории выполнено задание №1.

## Самый короткий ответ

> Программа читает команды из текстового файла и выполняет действия над целочисленными массивами. Массивы хранятся по именам в префиксном дереве. Для команды `Sort` используется моя косая куча. Готовые контейнеры и сортировки STL не используются.

## Как программа работает по шагам

1. `main` получает путь к файлу команд.
2. `Interpreter` читает команды до символа `;`.
3. `CommandParser` разбирает имя команды и её аргументы.
4. `TrieArrayStore` находит нужный массив по имени.
5. `IntegerArray` выполняет операцию над числами.
6. Ошибка одной команды выводится на экран, после чего программа читает следующую.

## Зачем нужны классы

### TextBuffer

> Это моя простая замена `std::string`. Он хранит символы в динамическом массиве и при необходимости увеличивает его.

Он нужен, потому что STL запрещена, а команды могут иметь разную длину.

### IntegerArray

> Это моя простая замена `std::vector<int>`. Класс хранит указатель на числа, текущее количество элементов и размер выделенной памяти.

Если места не хватает, метод `reserve` создаёт больший массив, копирует числа и удаляет старый.

### TrieArrayStore

> Это префиксное дерево для хранения массивов по именам. Каждый символ имени выбирает следующую ветку дерева. В конце имени лежит указатель на массив.

Например, имена `Arr` и `Array` сначала идут по общей ветке `A`, затем расходятся.

Поиск зависит от длины имени: `O(L)`. По условию имя не длиннее 16 символов.

### SkewHeap

> Это косая куча. Минимальное или максимальное число находится в корне. Главная операция `meld` объединяет два дерева и меняет их ветви местами.

Для сортировки все числа сначала добавляются в кучу, а затем по одному извлекаются из корня.

Сортировка: `O(n log n)`.

### CommandParser

> Этот класс идёт по тексту команды слева направо. Он отдельно читает слово, имя массива, запятую, число или путь к файлу и сразу проверяет формат.

### RandomGenerator

> Класс хранит одно число-состояние. По простой формуле он получает следующее псевдослучайное число.

`Псевдослучайное` означает, что числа вычисляются формулой, но выглядят случайными.

## Как объяснить команды

- `Load` — читает слова из файла; правильные целые числа добавляет, неправильные пропускает.
- `Save` — записывает все числа массива в файл.
- `Rand` — создаёт заданное количество случайных чисел в указанных границах.
- `Concat` — дописывает второй массив в конец первого.
- `Free` — удаляет все элементы массива.
- `Remove` — сдвигает оставшиеся элементы влево поверх удалённых.
- `Copy` — создаёт новый массив из выбранной части старого.
- `Sort` — помещает числа в косую кучу и извлекает их в нужном порядке.
- `Shuffle` — идёт с конца массива и меняет каждый элемент со случайным предыдущим.
- `Stats` — одним проходом ищет минимум, максимум и среднее; двойным циклом считает частоты.
- `Print` — выводит один элемент, диапазон или весь массив.

## Сложность простыми словами

- `Load`, `Save`, `Concat`, `Copy`, `Remove`, `Shuffle`, `Print`: `O(n)`, один проход.
- `Sort`: `O(n log n)`.
- `Stats`: `O(n²)`, потому что частота считается двумя вложенными циклами.
- Поиск массива по имени: `O(L)`, где `L` — длина имени.

## Слова C++, которые могут спросить

- `char*` — адрес начала массива символов.
- `int*` — адрес начала массива целых чисел.
- `new[]` — выделить динамический массив.
- `delete[]` — освободить его.
- `const` — запрещает менять значение через этот параметр.
- `&` после типа — передать существующий объект без копирования.
- `virtual` — дочерний класс может дать свою реализацию метода.
- `override` — метод заменяет виртуальный метод родительского класса.
- `throw` — сообщить об ошибке.
- `try` и `catch` — обработать ошибку без аварийного завершения.
- `template` у `shuffle` — метод может работать с объектом генератора подходящего типа.

## Зачем копирование и деструкторы

> Объекты сами владеют динамической памятью. Поэтому копия должна получить отдельную память, а деструктор должен освободить память своего объекта.

Если просто скопировать указатель, два объекта будут считать один участок памяти своим. Это приводит к ошибкам. Поэтому используются конструктор копирования, оператор присваивания и деструктор.
